\chapter{Prólogo}

Antes de enviar:
\begin{itemize}
	\item Escribe algunos casos de prueba simples si los ejemplos no son suficientes.
	\item ¿Están cerca los límites de tiempo? Si es así, genera casos máximos.
	\item ¿El uso de memoria está dentro de los límites?
	\item ¿Podría haber algún desbordamiento?
	\item Asegúrate de enviar el archivo correcto.
\end{itemize}

Respuesta incorrecta:
\begin{itemize}
	\item ¡Imprime tu solución! Imprime también la salida de depuración.
	\item ¿Estás limpiando todas las estructuras de datos entre casos de prueba?
	\item ¿Puede tu algoritmo manejar todo el rango de entrada?
	\item Lee nuevamente el enunciado completo del problema.
	\item ¿Manejas todos los casos límite correctamente?
	\item ¿Has entendido correctamente el problema?
	\item ¿Hay variables no inicializadas?
	\item ¿Algún desbordamiento?
	\item ¿Confundes N y M, i y j, etc.?
	\item ¿Estás seguro de que tu algoritmo funciona?
	\item ¿Qué casos especiales no has considerado?
	\item ¿Estás seguro de que las funciones STL que usas funcionan como piensas?
	\item Añade algunas aserciones, tal vez vuelve a enviar.
	\item Crea algunos casos de prueba para probar tu algoritmo.
	\item Revisa el algoritmo con un caso simple.
	\item Revisa esta lista nuevamente.
	\item Explica tu algoritmo a un compañero de equipo.
	\item Pídele a un compañero que revise tu código.
	\item Da un pequeño paseo, por ejemplo, al baño.
	\item ¿Es correcto tu formato de salida? (incluyendo espacios en blanco)
	\item Reescribe tu solución desde el principio o deja que un compañero lo haga.
\end{itemize}

Error de tiempo de ejecución:
\begin{itemize}
	\item ¿Has probado todos los casos límite localmente?
	\item ¿Hay variables no inicializadas?
	\item ¿Estás leyendo o escribiendo fuera del rango de algún vector?
	\item ¿Alguna aserción que podría fallar?
	\item ¿Alguna posible división por 0? (por ejemplo, mod 0)
	\item ¿Alguna posible recursión infinita?
	\item ¿Punteros o iteradores invalidados?
	\item ¿Estás usando demasiada memoria?
	\item Depura con reenvíos (por ejemplo, señales remapeadas, ver Varios).
\end{itemize}

Límite de tiempo excedido:
\begin{itemize}
	\item ¿Tienes algún bucle infinito posible?
	\item ¿Cuál es la complejidad de tu algoritmo?
	\item ¿Estás copiando muchos datos innecesarios? (usa referencias)
	\item ¿Qué tan grandes son la entrada y salida? (considera scanf)
	\item Evita vector, map. (usa arrays/unordered\_map)
	\item ¿Qué piensan tus compañeros sobre tu algoritmo?
\end{itemize}

Límite de memoria excedido:
\begin{itemize}
	\item ¿Cuál es la cantidad máxima de memoria que debería necesitar tu algoritmo?
	\item ¿Estás limpiando todas las estructuras de datos entre casos de prueba?
\end{itemize}
